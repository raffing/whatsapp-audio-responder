# WhatsApp Audio Responder - Web App

React web application for transcribing and analyzing audio messages.

## Development

```bash
# Install dependencies (from monorepo root)
npm install

# Start development server
npm run dev
```

## Environment Variables

Create a `.env.local` file in the monorepo root with:

```
GEMINI_API_KEY=your_api_key_here
```

## Build

```bash
npm run build
```

The built files will be in the `dist/` directory.
